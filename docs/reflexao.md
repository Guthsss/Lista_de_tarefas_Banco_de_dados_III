# Reflexão sobre Git e GitHub

## 1. Por que os Pull Requests são importantes em projetos colaborativos?

Os Pull Requests são importantes porque permitem que as alterações feitas por cada integrante sejam revisadas antes de serem adicionadas ao projeto principal. Isso ajuda a identificar erros, discutir melhorias e manter o código mais organizado.

## 2. Como acontece um conflito de merge?

Um conflito de merge acontece quando duas pessoas alteram a mesma parte de um arquivo de maneiras diferentes e o Git não consegue decidir automaticamente qual alteração deve permanecer.

## 3. Como a equipe resolveu o conflito encontrado?

A equipe analisou as alterações feitas por cada integrante, decidiu qual versão deveria ser mantida e realizou os ajustes necessários no arquivo. Depois disso, o conflito foi marcado como resolvido e o merge pôde ser concluído.

## 4. Qual prática de GitHub a equipe considera mais importante em projetos maiores?

A equipe considera a utilização de Pull Requests com revisão de código uma das práticas mais importantes. Em projetos maiores, isso facilita a colaboração, evita que alterações com problemas sejam adicionadas diretamente à branch principal e ajuda a manter a qualidade do projeto.
